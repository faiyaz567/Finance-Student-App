# 🎓 Student Budget Management System

A Python-based personal finance application designed for students to manage income, expenses, savings goals, and financial planning. The system provides budgeting tools, financial calculators, data export features, and an integrated chatbot to help students make informed financial decisions.

👥 Team Introduction

This project was developed as a collaborative effort by:

-Faiyaz Wasek Tahsin

Our goal was to create a practical budgeting solution that helps students manage their finances effectively, track spending habits, plan future purchases, and make informed financial decisions. Through this project, we applied Object-Oriented Programming (OOP), file handling, data management, and financial analysis concepts using Python.

## 📌 Features

### 💰 Income Management
- Add and track income sources
- Store income records with dates
- View total income

### 🛒 Expense Management
- Log daily expenses
- Categorize expenses (Food, Transport, Rent, Books, Fun, etc.)
- Track spending history

### 📊 Budget Analysis
- Balance overview
- Spending breakdown by category
- Monthly budget limit monitoring
- Debt-to-income ratio analysis

### 🎯 Financial Planning Tools
- Purchase Goal Builder
- EMI Planner
- Rent vs Buy Calculator
- Monthly Running Cost Calculator
- Post-Purchase Budget Rebalancer
- What-If Purchase Simulator
- Emergency financial planning tools

### 🤖 Student Budget Chatbot
- Interactive budgeting assistance
- Basic financial guidance and recommendations

### 📁 Data Management
- CSV-based data storage
- Export financial data to CSV files
- Persistent record keeping
